I kept finding old scrobbles filed under a single, or with no album at all, long after the song had landed on an album. My top albums never looked right, so I built this. It reads your history, shows how many plays are filed in the wrong place, and lists the fixes that make the biggest difference.

Get your full history as a file at lastfmstats.com: enter your username, wait for it to load, then use Export. The file is read in this browser and never uploaded. No API key needed, whatever the size. It is a snapshot, so after fixing things on Last.fm, export a fresh one.
